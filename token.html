Request Token GitHub
Halaman ini tidak menyimpan atau membagikan token milik siapa pun. Token adalah kunci pribadi ke akun GitHub Anda — jangan pernah menempelkannya di tempat lain selain kolom "Token GitHub" di aplikasi ini, dan jangan bagikan ke orang lain.

Kenapa perlu token?

Token ini dipakai aplikasi untuk mengunggah gambar chat ke repositori GitHub berikut atas nama Anda. Setiap orang yang ingin mengirim gambar membuat tokennya masing-masing — token tidak pernah dibagikan atau disimpan oleh siapa pun selain Anda sendiri.

Langkah membuat token

  1. Buka halaman pembuatan token GitHubKetuk tombol hijau di bawah. Anda akan diminta login ke akun GitHub jika belum login.
  2. Isi nama tokenBebas, misalnya arinex-chat, supaya mudah dikenali nanti.
  3. Pilih "Only select repositories"Lalu pilih repo yang tertera di atas. Jangan beri akses ke seluruh repo Anda.
  4. Atur izin "Contents" menjadi "Read and write"Cari di bagian Repository permissions. Izin lain biarkan default.
  5. Klik "Generate token"Token muncul sekali saja, formatnya github_pat_.... Salin sekarang juga.
  6. Tempel di aplikasiKembali ke Pengaturan → kolom Token GitHub, tempel, lalu ketuk "Simpan & uji koneksi".
